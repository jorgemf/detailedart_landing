# DetailedArt Landing Page

A modern, responsive landing page for DetailedArt - a platform that transforms photos into detailed art pieces.

## Dev locally

1. Start a local development server:
   ```bash
   # Using Python (if installed)
   python -m http.server 8000
   
   # Or using Node.js (if installed)
   npx serve
   
   # Or using PHP (if installed)
   php -S localhost:8000
   ```

2. Open your browser and navigate to:
   ```
   http://localhost:8000
   ```


## 🚀 Deployment GitHub Pages


1. Push your code to GitHub:
   ```bash
   git remote add origin https://github.com/yourusername/detailedart_landing.git
   git push -u origin main
   ```
2. Go to your repository settings on GitHub
3. Navigate to "Pages" under "Code and automation"
4. Select the main branch as the source
5. Your site will be available at `https://detailed.art`
